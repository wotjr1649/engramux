## 2. What M13 settled, and the one sentence that has to travel with it

**The candidate is *how much of the document the query accounts for*, and it is a property of the
pair.** An event class and a match location are properties of the document; this is the shape
neither M11 nor M12 had. The rule, the ladder, the condition and the two anchors were committed
before the gate existed, in their own commit, and the gate was written against a rule it did not
choose.

**Three thresholds of five clear M11's condition.** At 5,000 ppm `a reply's own words` goes from 76
of 139 to **92** and `a command line` **gains** one rather than holding level — which neither M11's
weight nor M12's rule managed on any class.

**Read the second table before quoting the first.** Over every harm candidate rather than the
sampled 25, **not one rung in the ladder regresses none of the three**: `an error message` drops from
79 of 96 at all five, and `a touched path` at three. The sampled arm shows neither. M11's own verdict
turned on a single document of 25 and its supplementary run *confirmed* the sample; this one
contradicts it, which is the other thing a supplementary run is for.

**The condition was not moved, and that is the decision this session made rather than a detail.**
Rewriting it now to take the larger populations in would be choosing a rule after seeing which answer
it gives. It stays as registered, the verdict stands as the gate reports it, and both tables are
pinned. **What that leaves is a licensed schema change with a sweep still owed** — a length column
and a migration are licensed, a shipped term is not, and the sweep that would decide one has to be
over the full populations because that is where the harm the sample cannot see already is.

**On the gain class alone this is the weakest of row 53's three candidates**, and the tidy reading is
the wrong one. M11's document rule bought thirty-one replies at the same weight and M12's location
rule thirty-three, against this one's sixteen. What separates it is that both of those lost a touched
path and this one loses none of the five. **A gain figure quoted without its harm arm says nothing**,
and that sentence is the most portable thing in this section.

**Three instruments now agree about one class.** `a prompt's own words` is 6 of 17 at weight 0, 6
under M11's rule, 6 under M12's, and 6 at every rung of M13's ladder. The eleven buried prompts of
M11's non-vacuity arm are buried by more than any of these terms can lift. That is a constraint on
whatever is tried next and not a result about any one of them.

**Two things the break-it pass said that no committed figure does.** Mutating the denominator so that
coverage is the query's length alone — a property of the query, not of the pair — leaves the reply
class at 78 where the pair rule reaches 92, so **it is the document's length earning the gain**. And
changing the threshold comparison from inclusive to strict, a one-document boundary flip, was caught
by exactly one count: `demoted` moving 208 to 209. **Pinning the mechanism figures and not only
recall is what has that resolution**, which is M11's and M12's discipline paying for itself.

**The measured reason this is not bm25 spelled twice** is in the spec and was probed before the
ladder was chosen: with the derived-field boost off the ranking puts a 52 B document above a 43 KB
one, so bm25's length normalisation is present and working — and with the boost on, both tool
documents move above the 52 B prompt. `boostPerDerivedToken` is flat and blind to the length of the
column it matched.

## 5. Things that will bite

1. **A wall-clock figure from one run is not comparable to one from another run on this machine, and
   the drift is large enough to invent a finding.** Session 23 measured `TestGateM12…` at 50 s;
   in this session's run of the same unchanged test it was **24.6 s**. Session 24 recorded
   `internal/search` at 151.8 s *before* M13 existed and this session measured **151.9 s** *after*
   adding a 50 s test to it — two figures that look like a free test and are a day's worth of drift on
   one machine. Nothing about the runs was controlled except the tree. **Read a ratio inside one
   run** — here M13 is 50.0 s against M12's 24.6 s and M11's 19.2 s, all in one `-v` pass — and treat
   any absolute second figure in this repository as a range. This is AGENTS.md's last table row about
   corpora, in the shape where the free variable is the machine rather than the data. **Under `-race`
   the same package now has three readings on three days** — 2,563 s, 2,110.8 s and this session's
   **2,500.2 s** — and only the last has M13 in it. Arithmetic on that pair says M13 costs about 800 s
   under `-race` and the machine gave most of it back; neither half of that is a number to plan a
   schedule on. What is solid is that the whole race run took about **43 minutes against
   `scripts/race.sh`'s 90-minute budget**, so the headroom is now under half and the next expensive
   gate should say what it will cost before it is written.
2. **A mutation that turns `a && b` into `a` does not compile**, because `b`'s only reference goes
   with it and Go makes an unused local an error. That is AGENTS.md's own row and this is the third
   session to meet it; the mutant is **discarded, not counted as killed**. The mutation that works is
   `a || b`, which changes the answer instead of removing the reference — it took M13's licensed list
   from three thresholds to five.
3. **A `bash` heredoc containing a backtick is refused before it runs**, by a guard that reports
   unparseable compound shell syntax — a backtick inside the body reads as an unclosed command
   substitution however it is quoted. Prose about this codebase is full of backticks, so this is not
   rare. Use the file-edit tool for that text rather than a heredoc; it is the same edit and the guard
   is asking for exactly that. AGENTS.md's *For coding agents* now carries the row.
4. **The agent's file-write tool refuses any path under `.git/`.** A scratch file for a splice goes in
   the working tree and gets deleted, which is also the safer of the two.
5. **Pin the mechanism figures, not only the verdict.** M13's `demoted` counts caught a `>=` changed
   to `>` — one document in 901 sitting exactly on a threshold — where every recall figure in both
   tables was identical. A gate that pinned its verdict alone would have called that mutation
   survivable.
6. **`.capture/`-dependent gates skip silently without it.** M11, M12, M13 and M8's corpus arm all
   do. A green run on a machine with no corpus has measured nothing, and the skip is the only thing
   that says so.
7. **Do not paste a `TestPhase4Gate` corpus-mode run anywhere.** One line of it carries a real path.
8. `go test` without `-p 1` is refused by a guard, on the command line and not in `GOFLAGS`.
